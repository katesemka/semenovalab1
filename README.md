Лабораторная № 1. Поиск по каталогу землетрясений

Вариант: earthquakes-jsonl | all | raw | fuzzy-words | top10 | plain | stars

- данные - землетрясения в формате JSONL (одна запись - одна строка JSON);
- поиск по всем текстовым полям; 
- текст не обрабатывается (raw): регистр и знаки препинания учитываются;
- каждое слово запроса должно найтись в записи, допускаются опечатки;
- показываются до 10 лучших записей;
- записям можно ставить оценки от 1 до 5, на порядок выдачи они не влияют.

Запуск: python main.py

Файлы 

main.py - цикл ввода команд, вывод ошибок 
commands.py - разбор и выполнение команд 
config.py - поля и их типы, поля поиска, операторы фильтров, порог, лимит выдачи 
models.py - состояние программы 
storage.py - загрузка файла и сохранение выдачи 
filters.py - фильтры 
search.py - поиск и релевантность 
output.py - вывод карточек, полей, фильтров и оценок 

Загрузка

- id и title обязательны;
- отсутствующее поле, null и пустая строка считаются пустым значением, в карточке выводится -;
- тип каждого поля проверяется, целые числа в числовых полях приводятся к float;
- id не должен повторяться;
- при ошибке в любой строке файл не загружается, выводится номер строки.

Поиск

Поиск идёт по полям id, title, kind, network, time, url. Текст запроса и текст
записи делятся на слова по пробелам (split()), больше никаких изменений не делается.

Сходство слов

Используется расстояние Левенштейна d(a, b) — наименьшее число вставок, удалений и замен
символов, чтобы получить из одного слова другое. Сходство:


sim(a, b) = 1 - d(a, b) / max(len(a), len(b))


Значение от 0 до 1, 1 полное совпадение. Пример: alaska и Alaska отличаются одной
буквой, sim = 1 - 1/6 ≈ 0.83.

Порог

Порог задаётся командой threshold в интервале (0, 1], по умолчанию 0.8.

Когда запись подходит

Для каждого слова запроса q ищется самое похожее слово записи:


best(q) = наибольшее sim(q, w) среди всех слов w записи


Запись подходит, если best(q) ≥ порог для каждого слова запроса.

Релевантность

relevance = (best(q1) + best(q2) + ... + best(qn)) / n

Среднее лучших сходств по всем словам запроса. Пример: запрос Alaskaa km, в записи есть
Alaska и km: (0.86 + 1) / 2 ≈ 0.93.

Пустой запрос проверяет только фильтры, релевантность равна 0.

Выдача

Подходящие записи сортируются по убыванию релевантности, выводятся первые 10.
Выводятся число найденных и показанных записей и время поиска.

Фильтры

строка eq, ne, contains 
число eq, ne, lt, le, gt, ge 
логическое eq, ne (значения true, false) 

Фильтры применяются одновременно, до ограничения в 10 записей. Пустое поле не проходит
ни один фильтр.

Оценки

rate <id> <1..5> ставит оценку записи из последней выдачи (show или search).
Повторная оценка заменяет предыдущую. Оценки хранятся до выхода или новой загрузки
и выводятся в результатах поиска. ratings показывает все оценки.
